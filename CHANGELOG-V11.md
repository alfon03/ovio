# OVIO Beta v1.1 — Seguridad de acceso

- Añadido flujo de solicitud de recuperación desde iniciar sesión.
- Mensaje no enumerativo para direcciones de correo registradas o no registradas.
- Pantalla independiente para establecer contraseña nueva desde URL de recuperación autenticada.
- Confirmación de contraseña y política local de 12–128 caracteres.
- Cierre de sesión después de actualizar contraseña.
- Envío de enlace de restablecimiento también desde Ajustes → Seguridad de la cuenta.
- Añadidas pruebas unitarias para política de contraseña y URLs de recuperación.
- No requiere migración SQL. Preserva todas las tablas y datos de la v1.0.
